# Getting started with XActions

XActions - The Complete X/Twitter Automation Toolkit. Scrapers, MCP server for AI agents, CLI, and browser scripts. No API required. Open source by @nichxbt. Don't Panic.

## Install

```bash
npx xactions profile nasa
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/XActions.git
cd XActions
```

Available commands:

| Command | Runs |
|---|---|
| `npm run dev` | `NODE_ENV=development nodemon api/server.js` |
| `npm run start` | `NODE_ENV=production node api/server.js` |
| `npm run test` | `vitest run` |
